# 最深之剑汉化版

《Deepest Sword》简体中文 WebGL 汉化版。

- 汉化署名：锅巴汉化、人民汉化
- 汉化用爱发电，永不收费
- 更多放置类汉化游戏：[gityx.com](https://gityx.com)
- 原作：Cosmic Adventure Squad

玩家可见文本、游戏内对话和 TextMeshPro 中文字体已完成适配。发布资源使用 gzip 无损压缩，并在浏览器端本地解压，以兼容 GitHub Pages。

本汉化仅供个人学习、研究与非商业体验。禁止转载、二次分发、打包发布及商业使用。原游戏相关权利归原作者及相应权利人所有，详细说明见 `NOTICE_zh.txt`。
